# 分店铺导入商品

入口：美客多店铺 → 独立店铺 → 打开目标店铺 → **导入商品**。

使用目标店铺自己的授权。打开任务后点击“刷新进度”查看新增、更新、失败数量和逐条结果，也可从“商品导入记录”菜单查看历史。数量按刊登统计，每个刊登可能包含多个商品变体。

后台分批导入标题、原币价格、SKU、首张图片、平台状态、平台可售数量和变体，自动关联店铺。平台没有描述时保留已有描述。原币价格保存在商品的 MercadoLibre 价格字段，此流程不自动换算币种或调整 Odoo 实物库存。

重复导入按刊登 ID 更新。不同刊登的相同 SKU 不自动合并。旧商品主体可在没有歧义时补齐变体并保留原商品 ID；已有业务记录且无法确认对应变体时，记录失败原因供人工核对。

失败或部分失败时可点击“重试未完成商品”；成功明细会保留。取消任务不会删除已导入商品。每家店同时只能运行一个导入任务。

发起人需要美客多管理权限和商品创建、编辑权限，并能访问店铺所属公司。后台按发起人的权限处理。

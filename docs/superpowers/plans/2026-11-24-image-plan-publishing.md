# 图片方案汇总与发布实施计划

**目标：** 按目标图库原始顺序汇总同一生成计划的图片，允许调整，并安全发布到对应 Mercado Libre 商品。

**约束：** 商品快照、公司、生成计划、图片证据和质检结果必须逐项校验；平台写入必须由用户明确确认，结果未知时先核对；不得覆盖无关规格或猜测平台模型。

1. 以图库原始序号与目标图产物 ID 建立稳定映射，覆盖旧计划、乱序生成及无效映射。
2. 同计划生成结果汇总为统一图片方案，服务端逐图核验来源、质检和快照，支持排序和持久化。
3. 工作台展示目标与生成图、进度、调整和人工处理，生成汇总预览。
4. 识别传统和 User Product 模型，读取平台当前图片和商品归属，构造发布前后对比；未知模型禁止写入。
5. 发布操作持久化、去重，先上传后更新并回读；超时进入待核对，记录各阶段及平台错误。
6. 覆盖权限、竞态、旧图保留、平台更新冲突、失败重试与浏览器端到端验证。

## 平台执行约束

- 发布请求必须先持久化，用户、店铺、快照、方案和平台预览摘要不可改变。
- 每次外部写入在独立事务中先落盘为已派发，再调用平台；调用结果不明确或进程中断时进入待核对，禁止自动重复。
- 每次上传完成单独记录平台图片 ID；更新前重新读取目标模型、站点映射及完整旧图清单，与确认过的预览比对。
- User Product 使用已验证的 UP Siteless ID；传统多规格刊登必须由用户逐次选择一个 SKU，保留并核对其他 SKU 的图片。
- HTTP 成功不等于最终生效；回读平台图片 ID 和顺序完全一致后才标记已发布。
